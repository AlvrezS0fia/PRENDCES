Paso 01

Promise básica: obtener un post

Usamos fetch(), que devuelve una Promise. Encadenamos .then() para procesar la respuesta y .catch() para los errores.

Paso 02

Promise + array: lista de usuarios

La API devuelve un array de usuarios. Con .map() transformamos cada usuario en HTML.

Paso 03

Promise.all: post + autor + comentarios

Disparamos 3 peticiones en paralelo. Si una falla, todas fallan: es una operación atómica.

Paso 04

Promise.allSettled: 5 posts independientes

Se lanzan 5 peticiones. Si una falla, las demás continúan: este combinador nunca rechaza.

Paso 05

Promise.race: carrera contra el tiempo

Competimos la petición a la API contra un temporizador de 2 segundos. El primero en resolver define el resultado.
